## 1. 实现与运动表示

```
vmm/video_io.py        cv2 读写（无 ffmpeg）+ 帧数/分辨率/fps/值域一致性校验
vmm/phase_pyramid.py   pyrtools SteerablePyramidFreq 封装（逐级降采样；复用实例重建）
vmm/temporal_filter.py butter + filtfilt 零相位带通；奈奎斯特与周期数校验；|H(f)|² 诊断
vmm/phase_magnifier.py PhaseBasedMagnifier(..., phase_clip, amp_floor, phi_dtype) + amplify_chunked
vmm/synthetic.py       合成序列（真值位移曲线 + 活动区掩码 + **内缩测量窗口 roi_core**）
vmm/metrics.py         5 套独立估计器 + 分区能量 + 重建误差/伪影/闪烁 + 接缝度量
```

**运动表示**：逐帧复数可转向金字塔 $C_{s,o}=A_{s,o}e^{j\phi_{s,o}}$ →
无环绕增量 $\delta\phi_t=\arg(C_tC_{t-1}^{*})$ → 累积 $\Phi_t=\sum_{\tau\le t}\delta\phi_\tau$ →
零相位带通 $\Phi_{bp}=\mathcal B_{[f_l,f_h]}(\Phi)$ → 重建 $C'=C\,e^{j\alpha\Phi_{bp}}$（幅值不变）。
**α=0 ⇒ 输出=输入**（误差仅金字塔重建误差）。α 是**额外**增益，线性区总量 ≈ 1+α，**不是** FD4MM 的 m。

**分块流式**（长视频）：`amplify_chunked` 用 overlap-save——每块取 `[s−margin, e+margin)`
整段滤波只保留中段，`margin = max(3·fps/f_lo, 30)` 帧（f_lo=0.3Hz@30fps → 300 帧）。
`phi_dtype=float16` 可再省一半内存（α=0 走不改系数路径，恒等性不受影响）。

## 4. 消融：相位上限的作用

α=10、shm_h、用主估计器复测：

| phase_clip | 增益 | 运动轴相关 | max\|out−in\| | β_max |
|---|---|---|---|---|
| **不限** | **10.47** | **+0.971** | 0.269 | 34.9 rad |
| 1.0 | 5.11 | +0.973 | 0.193 | 1.0 |
| 0.5 | 3.09 | +0.968 | 0.111 | 0.5 |
| 0.25 | 2.05 | +0.973 | 0.057 | 0.2 |

**结论**：不加限制时增益与保真都最好；相位上限**只按比例降低增益**，换来**逐像素偏差更小**。
它是"**用增益换视觉温和度**"的旋钮（真实视频大 α 下若纹理破坏可用 `--phase-clip 1.0`），
**不会**提高增益。（上一版"加上限能同时提升增益"的说法源于估计器退化，已作废。）

## 6. 本阶段抓到并修正的 6 个测量/方法错误（全是测量侧）

1. **逐帧速度当振幅**：0.5px/0.5Hz 的逐帧速度仅 0.052 px，而相位相关噪声底 ~0.10 px ⇒ 增益低估一半。
2. **零运动分母**：静止背景输入能量≈0 ⇒ 比值爆到 1e8。
3. **灰度定义不一致**：`metrics` 三通道平均 vs 输出 Rec.709 ⇒ 真实视频 α=0 报成 0.95。
4. **参考帧用时间平均帧**：被运动模糊抹掉纹理 ⇒ 干净序列相关 0.815，加噪反而 0.986。改**首帧**。
5. **单估计器下结论 + 用错轴**：`pyr` 在干净序列低估 3 倍却拿来算增益 ⇒ 误判"饱和"；竖直运动误用 x 轴判方向。
6. **局部运动的窗口错误（v3 修正）**：`lk_displacement_to_reference` 未透传 `roi`（在全帧上跟踪静止背景 → 报 0.0001 px）；
   且测量窗口取在 patch 的**裁切边界**（边界在窗口内不动，相位相关读到"内部动+边界静止"的混合，振幅偏大 46%）。
   加 `roi` 透传 + 内缩窗口 `roi_core` 后：输入 0.4985（真值 0.500）、α=10 增益 10.57、相关 +0.97 ⇒ `local` 由 FAIL 转 PASS。
   并补了回归测试 `test_lk_estimator_measures_localized_motion_with_roi` 防止复发。

另识别出两个估计器自身失效：投影傅里叶相位（主频 k0=1）、LK 用平均帧参考（报假零位移）。

**教训（写进 D7）**：测"放大"这件事本身很容易造假象——必须多估计器交叉 + 合成真值甄别 + 报不确定度。

## 8. 结论、局限与下一步

**结论**：阶段 1 基线**已建立并通过全部验收项**（判定 `all_pass=True`，106 测试通过）。
运动放大在合成域按 (1+α) 成立（α=10 达 94–97%，波形相关 ≥0.97），α=0 严格恒等（2e-6），
纯静止零误放大，无 NaN/Inf/黑帧/接缝，分区能量与噪声对照齐备，长视频分块流式可用。

**已知局限（如实列出，不许掩盖）**：
1. **真实视频的增益不可精确测**（振幅 0.03 px 接近估计器噪声底）——只能给能量比与不确定度。
2. **静止背景被同步放大**（带内 ×1.19–3.21，选择性仅 1.2–1.5）——阶段 1 无可靠性门控，这是设计如此。
3. **局部运动在 patch 边界有渗漏**（大 α 时环能量达 patch 的 20%，远背景 0.2%）——粗层空间支撑过宽。
4. 零相位滤波用未来帧 ⇒ **离线**，非实时。
5. 真实视频的帧率/频带需人工指定（未做自动频带选择）。

**下一步（阶段 2，需用户确认后启动）**：确定性运动可靠性门控
（`w = A²/(A²+σ²)` 类权重 + 逐带 β 上限 + `amp_floor` 低幅值抑制），目标：
在保持真实运动增益的同时把静止区带内放大从 3.21 降到接近 1，并压低 patch 边界渗漏。
阶段 2 验收通过后再考虑阶段 3 的 DiLA/DINOv2 融合。
