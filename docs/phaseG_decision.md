# Phase G 决策：是否重开 Phase E（DINOv2/DiLA 融合）

> 依据：`docs/phaseG_results.md`、`outputs/stage2_coherent/gates.json`
> 预注册 Gate（跑实验前写死）：G1 ≥ 2.0、G2 ≥ 1.5、G3 < 1.0（+ 运动保真度/平滑对照/种子复现）

---

## 1. 决策：**NO-GO — 不重开 Phase E**

| Gate | 阈值 | 实测 | 判定 |
|---|---|---|---|
| G1 运动/噪声可分性（0.05 px + σ=0.02） | ≥ 2.0 | **1.112** | ❌ |
| G2 噪声下定位对比 | ≥ 1.5 | **1.128**（IoU 0.073 ≈ 随机） | ❌ |
| G3 外观混淆（纹理/运动） | < 1.0 | **10.24**（亮度 0.0 ✓） | ❌ |
| 运动保真度 | 不显著下降 | σ_z 匹配时 **0 损伤**；但工作点增益 1.41–1.55 vs 2.28 | ⚠️ |
| 相对同窗长平滑的额外收益 | 存在 | **存在**，但只在 σ≲0.002 | ⚠️ |
| 3 种子复现 | 是 | σ 边界扫描一致 | ✅ |

**结论**：多帧相干积累**没有**在目标工作点把"真实微小运动 / 非运动扰动"分开。
因此**不训练 F2/F3/F4**，**保留 B2 为最终系统**，DiLA/DINOv2 继续作为独立研究分支。

---

## 2. 逐条回答任务书 §8 的六个问题

1. **多帧积累是否改善了真实运动与噪声的可分性？**
   *在干净条件下大幅改善*（证据对比 1.00→42.4、IoU 0.097→0.877），
   *在目标工作点没有改善*（G1 1.112，W=5→9 只从 1.1119 到 1.1120）。

2. **改善是否超出普通时间平滑的效果？**
   是。同窗长均值/中位数（G1/G2）对干净片增益只改 ≤3%、且**不产生任何逐像素证据**；
   相干族的空间选择性来自**非线性包络检测**（`|解析信号|²` 的窗均值），不是低通。
   但这一优势只在干净/低噪声片子上成立。

3. **DINOv2/DiLA 是否仍有必要？**
   **在本任务的目标（0.03–0.05 px、σ=0.01–0.02）上没有必要**——
   两条路都在同一个信息量上限上失败：DINOv2 的运动/噪声比 1.000（Phase D），
   相干相位证据 1.112（Phase G）。相位证据更便宜（0.21 s/8 帧 → 8 s/120 帧 vs
   DiLA 2.9 GB 显存 + 模型加载），且不引入学习分支的可复现性负担。

4. **如果要重开 Phase E，最值得验证的哪个单一辅助模块？**
   不是 DINOv2/DiLA，而是**空间一致性检验**：真实平移引起的相位变化场应与图像梯度
   方向一致（`Δφ(x) ≈ ⟨∇I(x), d⟩`），而纹理/遮挡引起的变化不与梯度对齐。
   这是一个**确定性、可解释**的统计量（对 `Δφ` 与 `∇I` 做局部最小二乘，取 R²），
   直接针对本阶段唯一没解决的 G3（纹理混淆 10.24×），且**不需要训练**。
   若它能把 G3 压到 <1，再评估是否需要学习式分支。

5. **是否需要配对训练数据、外观归一化或暂态处理？**
   * 若仍要走 DINOv2 路线：**需要**配对（同噪声、有/无运动）训练数据 + 外观归一化
     （Phase D 已给出量化理由：噪声 38×、亮度 0.75×、纹理 34.6×）。
   * 若走相位 + 空间一致性：**不需要训练数据**，只需合成真值做标定。
   * DiLA 分支若要用，**必须先去 SSM 时间暂态**（Phase D：相同输入帧下
     结构码 2.0e-2、Δz 0.232、解码器 0.197 px）。

6. **当前证据是否足以支持投入训练成本？**
   **不足**。G1/G2/G3 全部未达标，且差距是量级级别（1.11 vs 2.0、1.13 vs 1.5、
   10.2 vs 1.0），不是"再调一下阈值"能解决的。投入训练只会在同一信息量上限上过拟合。

## 3. 保留什么 / 不做什么

**保留（已交付）**
* `vmm/coherent.py`（相干检测；默认 `coherent_mode="none"` ⇒ 与 B2 逐位一致）
* `scripts/phaseG_coherent_accumulation.py`（基线/消融/Gate 三合一口径）
* `tests/test_coherent.py`（12 个测试：恒等、静态、噪声、H/V/局部、窗长、帧数不足、回退、分块、NaN）
* `outputs/stage2_coherent/`（baseline/ablation/gates/noise_boundary/alpha_sweep + 日志）

**不作为默认**
* 相干证据在 σ≥0.002 时不可用（会误杀真实运动且无选择性）；
* `σ_z` 必须按片子噪声标定，**禁止跨噪声档复用**（否则增益 −80%）；
* G1/G2（平滑族）**不是**相干积累的实现，只能作对照。

**不做**
* 不训练 F2/F3/F4；不改 B2 默认参数；不把 DiLA 接进最终系统。

## 4. 建议的下一步（按性价比排序）

1. **空间一致性检验**（确定性，直击 G3）：`Δφ` 与 `∇I` 的局部一致性 R² 作为权重，
   在 0.5 Hz 纹理变化 vs 0.05 px 平移上验证能否把 G3 从 10.2 压到 <1。
2. **多帧 + 多尺度联合**：把相干幅度按尺度加权（粗尺度运动更强、细尺度噪声更大），
   看能否在不牺牲增益的前提下抬 G1。
3. 若 1+2 仍失败 ⇒ **接受当前能力边界**：VMM 在 σ≥0.01、0.05 px 的场景下
   只能做"全局放大 + 弱选择性"，并在文档中明确写死该适用域。
