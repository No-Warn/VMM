## 2. 数学定义

阶段 1：

```
Δφ_out = Δφ + α · Δφ_bp
```

阶段 2：

```
Δφ_out = Δφ + α_eff(s,o) · w(x, t, s, o) · Δφ_bp ,        w ∈ [0, 1]
α_eff(s,o) = min(α, β_{s,o})                                （§3 逐尺度逐方向上限）
```

其中 ``s`` 是尺度（金字塔层）、``o`` 是方向、``x`` 是像素、``t`` 是时间。
``w`` 由若干**独立证据**相乘得到（`combine_weights`，默认 product）：

| 策略 | 组成 | 定义 |
|---|---|---|
| **M0** | — | 无门控（= 阶段 1） |
| **M1** | ``w_A`` | ``A² / (A² + (g·σ_A(s,o))² + ε)`` |
| **M2** | ``w_A · w_stab`` | ``w_stab = Φ_bp² / (Φ_bp² + (g·σ_φ(s,o))² + ε)``（**单帧**相位信噪比） |
| **M3** | ``w_A · w_stab · w_coh`` | ``w_coh = \|⟨exp(i·δφ)⟩_{radius}\|``（局部空间相位增量方向一致性） |
| **B1**（第二轮新增） | ``w_A · w_band`` | 见 §2.3：**长时窗目标带谱集中度**（整段序列的频谱分布，离线） |
| **M4**（第二轮新增） | ``w_A · w_stab · w_band`` | 三者相乘 |

### 2.3 长时窗带内谱集中度 ``w_band``（解决真实视频冲突的关键证据）

单帧相位信噪比 ``w_stab`` 在微运动接近噪声底时会把**真实运动一起判为不可靠**
（第一轮实测：真实视频选择性从 1.43 掉到 1.24，退化成"整体降增益"）。
因此第二轮引入**离线可用**的长时窗证据（逐像素）：

```
w_band = E_band / (E_band + E_outside + ε)
E_band     = Σ_{f∈[f_lo,f_hi]} |DFT(Φ_bp − mean)|²
E_outside  = Σ_{f∉[f_lo,f_hi]} |DFT(Φ_bp − mean)|²
```

先去时间均值（去漂移）、乘 Hann 窗（压边界泄漏）；``ε`` 保证零信号时 ``w_band→0``
（无证据不给额外增益，保守）。
与 ``w_stab`` 的本质区别：``w_stab`` 看**瞬时幅度**，``w_band`` 看**整段的谱分布**，
对"周期性真实运动 vs 非周期噪声"更敏感。**代价**：需要整段序列（离线限制，任务书 §5 允许第一版离线）。
实测（真实视频 α=10）：**B1 把静止区额外放大 3.21→2.88、活动区只 4.60→4.31，选择性 1.43→1.50**；
而含 ``w_stab`` 的 M2/M4 是 1.24/1.30（更差）⇒ **``w_stab`` 应关闭**。

### 2.1 尺度统一（任务书 §2.1 的硬性要求）

``A`` 是**复数可转向金字塔某带某像素的幅值**，与输入图像同强度单位。
``σ_A`` 必须**在同一表示上**测：在**静止视频/静止 ROI** 上逐带统计 ``A(x,t)`` 的**时间标准差**，
再取空间稳健分位（默认中位数）。于是 ``A²`` 与 ``σ_A²`` 同量纲，``w_A`` 无量纲。
**禁止**把像素域噪声方差直接加到归一化后的带幅值平方上。
``σ_φ`` 同理，是 ``Φ_bp`` 的时间标准差（弧度）。

实现：`vmm/reliability.py::calibrate_noise(video_static, mask=...)` → `save_calibration/load_calibration`；
脚本 `scripts/stage2_calibrate.py`。**真实视频用静止 ROI 校准**（按时间能量低 40% 选元素）。

### 2.2 `amp_floor` 的真实含义（任务书 §4）

**阶段 1 的 `amp_floor` 只被声明与存储、从未参与计算**（审计结论，见下）。
阶段 2 把它实现为**运动表示层的幅值可信度软阈值**：

```
r          = A / median_band(A)            （无量纲：相对本带中位幅值）
w_ampfloor = r² / (r² + amp_floor²)        （amp_floor = 0 时完全关闭）
```

* 单位/归一化：**相对本带中位幅值的比例**，无量纲。
* 作用位置：**运动表示层**（乘在 β 上），不是像素重建后的幅度裁剪。
* **软**：``w > 0`` 对所有 A 成立（低对比度真实运动不会被清零）——
  任务书 §4 明令禁止清零，测试 `test_amp_floor_is_soft_not_hard_zero` 守住这条。
* 与像素域幅度限制**不共用名字**：若将来需要像素重建端限制，请另起 `recon_amp_clip`（阶段 2 未实现）。

### 2.4 [B2/B3] 归一化谱集中度（第三轮：修掉 `w_band` 的 T 依赖）

`w_band`（§2.3）是**无量纲比值**：它的绝对水平由序列长度 ``T``、带宽、窗函数、
**以及"是否已经带通"**共同决定；而它被**直接乘在 α 上**。实测同一**纯带内正弦**
（0.5 Hz、带 0.3–1.0 Hz、fps=30，经过与算法**完全相同**的带通）：

| T | 时长 | B1 的 ``w`` |
|---|---|---|
| 64 | 2.1 s | 0.998 |
| **120** | **4.0 s** | **0.719** |
| 240 | 8.0 s | 0.994 |

⇒ **同一条视频只因截断长度不同，用户看到的放大倍率就差 23%**（端到端：增益 4.635/5.886/5.694
对 E0 的比值是 0.997/**0.768**/1.000）。这是未闭环 #1 的**根因**，与"低对比度"无关。

B2（`mode="B2"`，`band_domain="bp"`，默认）——**只做增益归一化**：

```
c_ref = conc(纯带内正弦 @ 本片主导带内频点；同 T/fps/带/窗/带通)
w     = clip( w_band / c_ref , 0, 1/c_ref )
```

* **只改绝对增益**、**保持像素间比值**（因为除以同一标量），所以专门消除 T 依赖；
  上界取 ``1/c_ref`` 而不是 1，避免把"比参考更集中"的像素裁平而破坏选择性。
* 参考由 `occupancy_reference()` 在**同一管线**上现算（纯正弦 + 累积相位噪声），
  带 `lru` 式缓存；代价可忽略。

B3（`mode="B3"`）——逐像素频点匹配 + 减 null：

```
w = clip( (conc − null) / (c_ref(b*) − null), 0, 1 )
```

* 对**正好落在 DFT 频点上**的带内正弦给出 1；对**偏离频点/贴近带边**的真实运动
  会被过度压制（实测 0.35 Hz、T=120 时降为 0）⇒ **不作为默认**，只作对照。

**已知局限（必须记录）**：B2 的 ``c_ref`` 取自**本片自己的主导频点**。若输入
**完全没有运动、只有噪声**，主导频点就是噪声峰 ⇒ ``c_ref`` 被拉到噪声自身的谱形状
⇒ ``w≈1``（实测 0.85–1.11），**不会拒绝纯噪声**。因此 B2 的定位是
"**消除 B1 的 T 依赖增益漂移**"，不是噪声判别器；端到端上它仍不差于 E0
（`static_noise` α=5、T=120：E0 1.151 → B2 1.038），但**不得**把 B2 当独立抑噪手段。
测试 `test_b2_scalar_normalization_is_not_a_noise_detector` 把这条**固定**下来。

| `vmm/phase_magnifier.py` | `_collect_phase(collect_amp=...)`；`_compute_beta` 内计算 ``w``、``α_eff`` 与 §5 D2 的稳健时间抑噪；诊断新增 `alpha_eff / cap / w_mean / w_median / w_p10 / w_suppressed_frac / w_A_mean / w_stab_mean / w_coh_mean / w_band_mean / dphi_abs_mean / dphi_abs_p90` |
| `vmm/metrics.py` | `ring_and_far_masks`（§7.3 的边界环/远背景） |
| `vmm/synthetic.py` | `noise_seed`（**同一底图、不同噪声实现**，标定所必需） |

**§5 新增滤波的频响（已实测并落盘）**：`robust_temporal_smooth`（时间滑动中位数，非线性，
边界 `mode='nearest'`）的等效增益：

| 核长 | 0.1Hz | 0.2Hz | 0.5Hz | 0.8Hz | 1.5Hz | 3Hz | 8Hz | 12Hz |
|---|---|---|---|---|---|---|---|---|
| k=5 | 1.000 | 0.998 | 0.995 | 0.983 | 0.951 | 0.618 | 0.591 | 0.000 |
| k=9 | 0.999 | 0.995 | 0.978 | 0.937 | 0.809 | 0.000 | 0.409 | 0.000 |

⇒ k=5 对目标带（0.2–0.8 Hz）衰减 ≤2%、对 ≥3 Hz 抑制约 40%、12 Hz 清零；
k=9 会把 3 Hz 正好**陷波到 0**（中位数滤波非 LTI，对特定整数周期敏感）——这是它的**已知怪癖**，
故推荐 k=5。**不重复叠加既有 Butterworth**：本步骤作用于"已带通"的相位，是非线性稳健平滑，
作用与"再带通一次"不同（已在 `docs/stage2_results.md` §6 量化：D2 相对 D1 无额外收益）。

内存与耗时：启用门控时要额外存逐带幅值（与相位同量级，约 +1 倍）；实测 192×192×64 帧：
M0 1.8–3.4 s，M1/M2 3.4–4.1 s，M3 4.8–4.9 s（门控约 +30–60%）。
M0 路径不收集幅值 ⇒ 与阶段 1 完全同开销。

**逐带上限 β**：配置项 `per_band_caps`（`"level-orient" -> β`）。
`cap_suggestions()` 由统计给出**建议**（`α_max · clip(dphi_abs_mean/(σ_φ),0,1)`），
**只打印、不自动生效**（任务书 §3 禁止无实验手填）。

## 4. 失败方案与理由（实验已否定，不许再走）

| 方案 | 结果（实测） | 结论 |
|---|---|---|
| **M1 幅值门控单独使用** | 门控确实生效（``w_mean=0.719`` 每带），但**空间近似均匀**（只有 2% 像素 ``w<0.1``）→ 活动/静止/环/远背景的能量比**完全不变**（如 static_noise α=5 仍为 1.12）；只按比例降低增益 | **均匀权重不改变任何比值**。幅值分布中"噪声"与"真实微运动"高度重叠 ⇒ 只用幅值无法分离（数值证明任务书 §2.2 的警告） |
| **把最细尺度的 β 压到 1**（C1/C2） | local_noise α=5：增益 4.23→3.77/3.53，而静止带内比 1.14→**1.15/1.10**、环 1.21→**1.22/1.17**（M2 本身是 1.06/1.14） | 最细尺度**同时**承载噪声与运动；只压它 ⇒ 丢运动多于丢噪声，**比值反而变差** |
| **投影傅里叶相位**做位移读数（阶段 1） | 主频 k0=1，真值 0.5 px 报 0.002 px | 灵敏度不足，废弃（保留在 metrics 内并标注不可用） |
| **硬阈值清零低幅值系数** | 任务书 §4 明令禁止 | 改为**软**权重（2.2 节） |
| 标定底图与测试底图不一致 | σ_A 尺度错位 → M1 完全失效（M2/M3 不受影响，因为相位**尺度无关**） | 标定必须**同一底图、不同噪声实现**（已加 `noise_seed`） |
| 掩码直接用图像分辨率索引各带 | `boolean index did not match`（192 带 96×96、480 带 240×136…） | 逐带**最近邻重采样**掩码（已修 `_mask_for`） |
| **``w_stab``（单帧相位信噪比）用于真实微运动** | 真实视频选择性 **1.43 → 1.24**（活动区被压得比静止区更多）= 退化成整体降增益 | **应在真实微运动场景关闭**；改用长时窗 `w_band`（§2.3） |
| **§5 D2/D3（稳健时间抑噪 / 空间一致性）叠加在最优门控上** | 真实视频 α=10：D1 4.31/2.88 → D2 4.31/2.88 → D3 4.30/2.88，**无额外收益**；合成上 D2m(k=9) 还多损失 ~1.7% 增益 | 当前数据上**不推荐**叠加；收益已由门控本身取得（诚实负结果） |
| M3/M4s 的空间一致性平滑 | 真实视频 M4s2 把选择性 1.30→1.39、静止 1.86→1.67（代价：活动 2.42→2.32）；合成 local_noise 环渗漏 1.15→1.09 | **轻微正收益**，仅在"更看重渗漏"时作为可选叠加（D3b） |

## 5. 实验协议（任务书 §6/§7）

* 同一输入、同一频带、同一 ROI、同一 α 集合；**所有比较用同一测量器**（阶段 1 的
  `vmm/metrics.py`：5 套独立估计器 + 合成真值甄别；α=0 恒等走 2e-6 级别判定）。
* 指标：运动保留（振幅/增益/波形相关/与 1+α 偏差）、静止区带内能量 in/out/比值、
  **带外 guard 能量比**（是否引入新频率成分）、空间渗漏（活动/环/远背景）、
  恒等误差、NaN/Inf/黑帧/饱和、耗时。
* **禁止**用整体均值代替空间选择性；**禁止**只报最佳配置（必须同时报基线与各消融点）。

**注意协议差异**：首次消融用 T=64 帧（阶段 1 冻结基线是 T=120），
因此同一 α 下的绝对增益会略低（如 α=1 时 1.69 vs 1.96，源于短序列的零相位滤波边界效应），
**不得**把它当成回归或改进；跨阶段比较必须用同一 T（后续 `docs/stage2_results.md` 会统一到 T=120）。

## 6. 结论（两轮累计；详表见 `docs/stage2_results.md`）

* **推荐配置：`mode: B1`**（``w_A · w_band``，幅值证据 × 长时窗带内谱集中度），
  关闭 ``w_stab``、不启用逐带上限、不叠加 D2/D3；若更看重渗漏可加 ``spatial_smooth: 2``（D3b）。
* **真实视频（α=10）**：静止区额外放大 3.21 → **2.88**（−10%），活动区 4.60 → **4.31**（−6%），
  **选择性 1.43 → 1.50（首次不是"整体降增益"）**；带外 guard 0.82 → 0.83（**没有**引入新频率成分）。
* **合成带噪（local_noise, α=5）**：静止 1.14 → 1.07、**环 1.21 → 1.15**、远背景 1.14 → 1.07，
  增益 −3.5%；静止噪声案例静止比 1.12 → 1.06，无假运动（假位移始终 0.018–0.021 px）。
* **低对比度真实运动几乎零代价**：4.64 → 4.62（−0.4%）——因为相位证据与幅度无关；
  而 `amp_floor=1.0` 会损失 30%（4.64→3.23）⇒ `amp_floor` 建议 ≤0.1 或不启用。
* **已知局限（诚实）**：收益幅度**有限**（真实视频静止区仅降 10%），距任务书"3.21 为优化对象"的方向正确，
  但**不能**声称已把静止区降到接近 1.00 而保持运动；M1 单独使用无效（均匀权重）；
  逐带上限（尤其压最细尺度）是负结果；D2/D3 无额外收益。

## 7. 第三轮结论（接手后）：推荐从 B1 改为 **B2**

> 背景：接手后复核发现 §2.3 的 `w_band` 有一个**尺度问题**（§2.4），
> 它让"同一条视频只因片长不同，增益差 23%"。详细数据见 `docs/stage2_results.md` §11。

* **推荐配置改为 `mode: B2`**（`band_domain: bp`）：增益与片长无关
  （对 E0 的比值 **1.000/1.000/1.003** @T=64/120/240，B1 是 0.997/**0.768**/1.000），
  且选择性不降反升（合成 `local_noise` T=120：2.011→**2.191**；真实视频 α=5：1.479→**1.510**）。
* **B1 仍保留**：若唯一目标是压低静止区**绝对**能量，B1 更低（α=10：2.88 vs B2 3.08），
  但其中约 2/3 来自全局降增益 —— 报告时必须注明（任务书 §8）。
* **B2 的定位是"增益归一化"，不是噪声判别器**（§2.4 已知局限）。
* **B3/B2r 仅作对照**：真实视频 α=2 时 B3 只 1.55（E0 1.91）⇒ 过度压制。
* **不变的部分**：M0 逐位不变、α=0 恒等 2e-6 级、`w_stab` 关闭、逐带上限关闭、D2/D3 不叠加；
  真实微运动仍在估计器噪声底，**只能报能量比与选择性，不得声称精确倍率**。
