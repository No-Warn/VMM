# Phase G 结果：多帧相干积累的消融、噪声边界与 Gate 判定

> 代码：`vmm/coherent.py`、`scripts/phaseG_coherent_accumulation.py`
> 设计：`docs/phaseG_design.md`；决策：`docs/phaseG_decision.md`
> 数据：`outputs/stage2_coherent/`（`baseline_b2.json`、`ablation.json`、`gates.json`、
> `noise_boundary.json`、`alpha_sweep.json`、`repro_b2_check.json` + 对应 `.log`）
> 环境：A40 46 GB / py3.10.18 / torch 2.6.0+cu124；全部 CPU 路径（VMM 本身不用 GPU）
> 统一条件：192×192、T=120、fps=30、f=0.5 Hz、带 0.3–1.0 Hz、levels=4、order=3、gray

---

## 0. 结论摘要

1. **预注册 Gate 未通过 → NO-GO**：目标工作点（0.05 px 运动 + σ=0.02 噪声）下
   **G1=1.112（需 ≥2.0）、G2=1.128（需 ≥1.5）、G3_texture=10.24（需 <1.0）**。
2. **但有一个必须如实报告的部分成功**：在**干净**条件下，相干证据把局部运动定位对比
   从 B2 的 **1.00** 提到 **42.4**、IoU 从 **0.097** 提到 **0.877**（随机基线 ≈0.06），
   而且**放大路径一行未改** ⇒ 增益与波形与 B2 完全相同（α=1/2/5/10 逐位一致）。
3. **失败原因是信息量，不是窗长**：W 从 5→9，G1 只从 1.1119→1.1120。
   受目标运动半个周期（0.5 Hz → 15 帧）限制，可选窗长内能提供的相干增益不足以
   弥补 σ=0.02 下约 40 倍的噪声超出。
4. **平滑对照证实"不是普通低通"**：同窗长均值/中位数（G1/G2）对增益的改变 ≤3%、
   且**根本不产生证据图**；相干族的收益来自**非线性包络检测**（空间选择性），
   不是低通。但它同样救不了噪声场景。
5. **一个必须记录的工程结论**：`σ_z` 必须与片子的噪声水平匹配。
   用 σ=0.02 标定的 `σ_z` 去处理干净片，会把真实运动判成噪声，增益 5.847→**1.177（−80%）**。

## 5. 噪声边界（`noise_boundary.json`）：方法在哪里失效

`local` 0.05 px、G3 W=9、σ_z 按各噪声档标定：

| 输入噪声 σ | 输入估计 | G0 增益 / 对比 | **G3 增益 / 对比 / IoU** |
|---|---|---|---|
| **0** | 0.0501 px | 5.847 / 1.00 | **5.847 / 42.39 / 0.877** |
| 0.002 | 0.0542 px | 5.238 / 1.13 | 5.147 / **1.30** / 0.085 |
| 0.005 | 0.0565 px | 4.966 / 1.03 | 4.258 / 1.26 / 0.077 |
| 0.010 | 0.0659 px | 4.271 / 1.02 | 2.759 / 1.22 / 0.079 |
| 0.020 | 0.1163 px | 2.284 / 1.01 | 1.547 / 1.13 / 0.073 |

⇒ **适用边界只有 σ≲0.002**（且要按该噪声档标定 σ_z）；一旦 σ≥0.002，
证据对比就掉到 1.3（随机水平附近），而增益还要再损失 10–40%。
这与阶段 2"真实微运动已在测量器噪声底"的结论一致。

## 7. 失败案例与原因

1. **工作点（0.05 px + σ=0.02）**：G1=1.112。原因：噪声在相干检测后的幅度
   `A_noise≈2.52`，而真实运动只把它抬到 `2.81`（+11% 幅度、+27% 功率）。
   需要 ~7 倍功率提升才到 G1=2，即 W 需 ×49 —— 远超半个运动周期（15 帧）。
2. **纹理变化（0.5 Hz 局部）**：G3=10.24。原因：**同频带内的外观变化与运动
   在相位域不可分**（都是带内相位调制）。相位域的相干检测比 DINOv2 好 3.4 倍
   （Phase D 是 34.6×），但仍不足以区分。
3. **σ_z 错配**：用 σ=0.02 的 `σ_z` 处理干净片 → 增益 −80%。
   教训：`σ_z` 必须按片子的噪声水平标定（与阶段 2 `σ_A` 同一条纪律）。
4. **`local_lowc` 0.05 px**：输入运动 0.05 px × 0.15 对比度已低于测量器下限，
   增益不可测（诚实标注，不用不可靠读数）。

## 8. 计算代价

| 方法 | 每次运行耗时（T=120、192²） | 相对 G0 |
|---|---|---|
| G0（B2） | 6.3–7.0 s | 1.0× |
| G1/G2（平滑） | 6.2–7.5 s | ~1.0× |
| **G3/G4/G5（相干）** | **7.7–8.9 s** | **+25~27%** |

内存：每带多一个复数 `[T,h,w]`（120×192×192 complex128 ≈ 70 MB，逐带瞬态）；
`A` 的时间平均图只在 `debug_maps=True` 时保留。
延迟：居中窗 ⇒ `(W−1)/2` 帧（W=5/9/15 → 2/4/7 帧），离线算法。
